The dashboard gives CloudOps/NOC staff and leadership a single page to see:

1. Incidents — a reverse-chronological timeline of every VOTS incident
(currently 38+), each with category, impact, downtime, and a Jira link.

2. Problems / SLA — current-month Availability SLA against the 99.5%
target, with downtime and risk callouts.

3. Runbook / SOP — standard incident-handling and escalation procedures.

4. Architecture — a simplified view of the B300 cluster topology.

5. Workflow / ITIL — ITIL-aligned incident/problem/change process pages.

6. Onboarding questionnaire — a customer onboarding form driven by
historical incident patterns (RMA expectations, maintenance windows,
data-loss-on-reboot risk, bandwidth testing, etc).

It also has:

1. A day/night theme toggle (light/dark, CSS custom properties driven).
2. A 中文 / EN language toggle covering every tab and the login screen.
